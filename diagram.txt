2. CARA MENJELASKAN ALUR INI SAAT PRESENTASI (HANYA 1 MENIT)
--------------------------------------------------------------------------------

"Bapak/Ibu Penguji, alur DevSecOps yang kami bangun memiliki 5 tahapan utama:

1. Tahap Pertama (Developer):
   Saya sebagai developer (aristodanang) menulis kode aplikasi lalu melakukan 
   push ke GitHub dan membuat Pull Request.

2. Tahap Kedua (Pemicu / Trigger):
   GitHub secara otomatis mendeteksi Pull Request dan menjalankan pengujian keamanan.

3. Tahap Ketiga (4 Satpam Keamanan / CI Gates):
   Sebelum kode boleh masuk server, kode harus melewati 4 satpam digital:
   - Semgrep   : Menjaga agar tidak ada celah SQL Injection.
   - Pylint    : Menjaga standar mutu kode dan memastikan semua unit test lolos.
   - Pip-Audit : Memastikan dependensi Python tidak membawa virus/celah CVE.
   - Trivy     : Memastikan tidak ada password atau token yang bocor di kode.

4. Tahap Keempat (Gerbang Keputusan):
   - Jika ada satu saja satpam yang menemukan celah, pipeline LANGSUNG GAGAL 
     dan proses deployment dibatalkan seketika. Server VM tetap aman.
   - Jika semua lolos dan hijau, pipeline memberikan izin lanjut ke tahap deployment.

5. Tahap Kelima (Deployment ke VM):
   Agen Self-Hosted Runner di dalam VM mengambil kode yang sudah lolos uji, 
   membangun image Docker secara otomatis, dan menyalakan kontainer pada port 5000. 
   Aplikasi Tetris langsung aktif dan aman digunakan di http://192.168.139.137:5000."
