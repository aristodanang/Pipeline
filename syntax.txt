BAGIAN KODE YANG DIUBAH (SQL INJECTION):
File: Pipeline/app.py (pada fungsi login(), sekitar baris 68-75)

--------------------------------------------------------------------------------
A. KODE RENTAN (MEMICU SKENARIO PIPELINE GAGAL):
--------------------------------------------------------------------------------
Ubah query pada app.py menjadi string formatting / f-string:

        # RENTAN TERHADAP SQL INJECTION:
        query = f"SELECT username FROM users WHERE username = '{username}' AND password = '{password}'"
        cursor.execute(query)

  * Mengapa Pipeline Gagal?
    Pemindai Semgrep SAST secara otomatis mendeteksi query SQL dinamis yang tidak
    disanitasi (Kategori OWASP A03:2021 - Injection / CWE-89: SQL Injection).
    Hasilnya: Job "Semgrep SAST Scan" langsung MERAH (Failed / Exit Code 1).
    Tahap CD "Build & Deploy to VM" otomatis DIBATALKAN (Skipped). Server VM aman!

--------------------------------------------------------------------------------
B. KODE AMAN (MEMICU SKENARIO PIPELINE SUKSES):
--------------------------------------------------------------------------------
Kembalikan query pada app.py menjadi parameterized query:

        # AMAN DARI SQL INJECTION (PARAMETERIZED QUERY):
        query = "SELECT username FROM users WHERE username = ? AND password = ?"
        cursor.execute(query, (username, password))

  * Mengapa Pipeline Sukses?
    Nilai input dipisahkan secara struktural dari logika SQL, sehingga karakter
    injeksi berbahaya tidak akan dieksekusi sebagai perintah basis data.
    Hasilnya: 
    - Semgrep SAST Scan: HIJAU (0 Blocking Findings)
    - Pylint Code Quality: HIJAU (Skor 10.00 / 10)
    - Pip-Audit SCA: HIJAU (0 Known Vulnerabilities)
    - Aqua Trivy: HIJAU (0 Leaks / Secrets)
    - Tahap CD otomatis men-deploy ke Docker Host di VM!
